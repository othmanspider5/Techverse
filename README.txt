TECHVERSE — Technology Device Encyclopedia
============================================

This is an educational reference website, NOT an e-commerce store.
There is no shopping cart, checkout, payment, ordering or product sales.

Files:
- index.html: website structure
- style.css: design and responsive layout
- app.js: search, filters, pagination, language switching, theme and device profiles
- devices.js: catalogue data (900 indexed entries)

How to run:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. For publishing, upload the complete folder to a static host.

Important data-quality note:
The catalogue is an index of device/product families. Technical specifications can vary
by exact model code, regional SKU and configuration. Where a specification is not safely
established at this catalogue level, the profile explicitly says to verify it with the
manufacturer instead of inventing a number. Each profile includes a search link to help
locate the manufacturer's official information. This is not a claim that every field
has already been independently verified.

Languages: English, Arabic (RTL), French.
